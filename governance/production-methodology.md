# How Orvaya Studio Builds Films
Status: Public working methodology (not proof of completed production).

Orvaya Studio uses a human-directed systems engineering lifecycle:
**CONOPS → Requirements → Architecture → Design → Production → Verification → Validation → Release.**

Each episode aims to publish selected spoiler-safe requirements, tool records, AI/human contribution summaries, testing results and lessons learned.

## Transparency principles
1. Proposed tools are identified as proposed, not used.
2. AI-assisted work is identified and reviewed by a human.
3. Production claims are supported by evidence.
4. Private canon, unreleased scripts, personal data and unlicensed assets are not published.
5. Deviations and lessons learned are documented.
